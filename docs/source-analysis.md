# تحليل المستودع الأصلي

المصدر: `zeus82256-lang/C-app-new` عند commit `b47e7bd2721040dd46b30d13f65335fef72acf7d`.

شمل الجرد **125 ملفًا**: 115 ملفًا نصيًا بإجمالي 41,518 سطرًا، و10 ملفات صور/خطوط. قرأ مولد الجرد محتوى كل ملف لحساب بصمته، وحلّل AST لكل JavaScript/JSX لاستخراج الاعتماديات والدوال ومسارات HTTP ووسطائها. التقرير التفصيلي في `source-inventory.json`. المراجعة اليدوية التفصيلية ركزت على تدفقات المزودين والإعدادات والترجمة والتخزين والمصادقة؛ الجرد الشامل لا يعني اختبار كل سلوك لكل شاشة أو تنفيذ جميع اتصالات الإنتاج.

## المشاكل المؤكدة والمتعلقة بالطلب

1. **فقدان إطارات Gemini عند حدود TCP:** كان `chunk.toString().split('\n')` يحاول تحليل سطر JSON قبل اكتماله ثم يتجاهله. وقد تنقسم الأحرف متعددة البايت أيضًا. أصلح بقارئ `StringDecoder` مع buffer للأسطر واختبارات بتجزئة كل بايت.
2. **عدم التقاط النص النهائي المعدل:** كان القارئ يفضّل لقطات تمتد بالنص السابق أو أطول لقطة؛ الرد المعدل غير الممتد قد يضيع. يستخدم الآن آخر لقطة للنص المرشح، ويحدّث response/choice IDs لكل رد.
3. **كشف النقص بعلامة ترقيم:** تنتهي الملخصات والنصف الأول كثيرًا بنقطة، فيُقبل فصل ناقص. أضيف تقسيم وفحص تغطية الفقرات إلى مساري الترجمة والمترجم الخالص للمزودين الجدد وGemini Web.
4. **حالة المحادثة غير دائمة:** تخزين سياق jobs في الذاكرة لا يحفظه بعد إعادة التشغيل ولا يسمح باختيار مشروع/محادثات متعددة حسب الغرض. أضيفت إعدادات مهام ونموذج حالة دائم.
5. **عدم وجود ChatGPT Android:** أضيف نقل بروتوكول المرفق، بما فيه المشاريع والنماذج والمحادثات ورفع الملفات والصور.
6. **تكرار dispatch في ترجمة البيانات وتخصيص مولد العناوين لـGemini الرسمي:** وُحّد caller للبيانات وأضيفت محاولات مزودي المترجم للعناوين مع إبقاء مفاتيح Gemini القديمة كاحتياط.
7. **خوادم POW موروثة:** أضيفت خدمة 3MH كوكيل كامل وكخادم POW؛ أصبحت استجابة POW المكتملة ترميزًا مقبولة دون اشتراط `solved_json` غير المستخدم.
8. **الواجهة قد تفقد تحديث النموذج:** تحديث الحقول باستخدام مصفوفة providers قديمة كان يمكن أن يطغى على جلب النماذج عند تحديث النموذج والقائمة معًا. استُخدم functional state update، مع اختبار تحميل/حفظ الشاشة.
9. **عدّ الإنجليزية مرتين:** `getSourceMagnitude` كان يجمع English words ثم يعدها مرة أخرى ضمن otherWords. صُحح وفُحص للإنجليزية والسيريلية والصينية.
10. **قيم اعتماد ثابتة في المصدر:** أزيلت قيم ثابتة لحسابات/تخزين من النسخة الجديدة وأضيفت أمثلة بيئة خالية من الأسرار. لم تُنسخ كوكيز المستخدم المرفقة.

## ملاحظات قائمة خارج تعديل المزودين

- عدة نسخ من `getGlobalSettings()` تستخدم `Settings.findOne()` بينما التسجيل ينشئ Settings لكل مستخدم. هذا لا يحدد singleton حقيقيًا؛ اختيار وثيقة الإعدادات يحتاج ترحيلًا مدروسًا عند وجود إعدادات مستخدمين متعددة.
- المصادقة المحلية تستخدم SHA-256 مباشرًا لكلمات المرور، وتعيد user object الذي يتضمن حقل password في بعض الردود. يُنصح بتغيير سياسة التخزين وإخفاء هذا الحقل في عمل مستقل مع ترحيل كلمات المرور.
- يوجد وكيل صور يقبل URL خارجيًا؛ يلزم تقييم الوصول إلى عناوين الشبكات الخاصة في بيئة الإنتاج.
- الوظائف طويلة العمر تعمل داخل عملية Node؛ بقاؤها واستعادتها وتنسيقها عبر عدة replicas يحتاج تصميم تشغيل مستقل. القفل الجديد على المحادثات محلي للعملية.
- إصدار API في تطبيق Expo كان ثابتًا؛ أضيف `EXPO_PUBLIC_API_URL` مع الاحتفاظ بالقيمة الأصلية كافتراضي.
- لا توجد في المرفقات معلومات مثبتة لقوائم محادثات Gemini أو تحكمه بالتفكير. لم يُستنتج بروتوكول بديل من مستودعات أخرى.

لم تُغيّر هذه النسخة آلية التسجيل أو بنية التخزين الإنتاجي أو سلوك إنشاء حسابات Qwen تلقائيًا عدا إزالة التوكن الثابت. لا تعني نتائج اختبارات المزودين اكتمال تدقيق أمني لكل التطبيق.
