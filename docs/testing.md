## Gemini: التجربة الفعلية

المصدر: [Project Gutenberg، Alice’s Adventures in Wonderland](https://www.gutenberg.org/files/11/11-0.txt)، الفصل الأول فقط، وهو عمل من الملك العام في الولايات المتحدة. جُلب الفصل من بدايته حتى عنوان الفصل الثاني، بإجمالي **11,551 حرفًا**. توجد نسخة المصدر في `tests/fixtures/alice-chapter-1.txt`.

استخدم الاختبار الكوكيز المرفقة محليًا مع `/u/1` وبروتوكول الملف المرفق. ترجم 31 فقرة/جزءًا، متحققًا من علامات الفقرات وترتيبها وعلامة الإكمال. شملت تجربة أولية فشلًا صحيحًا في التعامل مع فواصل النجوم؛ صُحح الفحص للحفاظ على الفواصل ثم أعيد الفصل كاملًا ونجحت تغطية 31/31. لذلك أُضيف اختبار خاص بفواصل المشاهد.

بعد التغطية اجتازت الترجمة فحص جودة الفصل الموجود في الخادم بعد إصلاح بقايا كلمة أجنبية واحدة عبر `translateResiduesOnly` مع Gemini نفسه. طول الناتج النهائي **9,571 حرفًا**. تفقدت بداية الفصل ونهايته؛ انتهى عند تناول أليس الكعكة وفواصل المشهد، كما في المصدر. لا تعد الفحوص البنيوية مراجعة أدبية بشرية لكل جملة.

- النتيجة الرقمية: `gemini-live-result.json`.
- النص الناتج: `alice-chapter-1-ar.gemini.txt`، محتفظ به للمراجعة كما أعاده المزود بعد إصلاح البقايا.
- لم تنشر الكوكيز ولا معرّفات حساب المستخدم أو جلسة المحادثة. الكوكيز الأصلية بقيت في الملف المرفق خارج المستودع.

## ما تغطيه الاختبارات الآلية

- دفعات شبكة مفصولة على كل بايت، Unicode عربي مجزأ، CRLF، آخر سطر دون newline، انقطاع الشبكة، خطأ داخل التدفق، اللقطة النهائية المعدلة، وتحديث معرّفات المحادثة.
- اختيار مشروع ChatGPT وإنشاء محادثة فيه، متابعة parent الحالي، اختلاف المشروع، فصل نص التفكير عن الرد النهائي، رفض الرد الجزئي، رفع ملفات وصور ومنع تسريب ترويسات الحساب إلى خادم التخزين.
- معاملات DeepSeek Worker، بما فيها القيم الصفرية، التفكير والبحث، session/parent، الرد الفارغ والخطأ وحد المخرجات ووجوب التوكن.
- فصل الحالة حسب الحساب والمزوّد والمهمة وjob، تغيير المحادثة المختارة، وضع المحادثة الجديدة، تسلسل الكتابات، وحفظ الحالة في MongoDB.
- تغطية فصل حقيقي مع مزود محاكى، فقرات صينية طويلة، فواصل المشاهد، رفض الفقرات المحذوفة والمكررة والمعاد ترتيبها والتلخيص الواضح، وحد إعادة المحاولات.
- HTTP لإعدادات الحسابات، المصادقة والصلاحيات، قوائم المشاريع والنماذج والمحادثات، إنشاء/متابعة المحادثة، multipart ورفض الملفات الكبيرة، وعدم إعادة أسرار المزود.
- الواجهة: حفظ الاختيارات المستقلة، اختيار محادثة المشروع، إنشاء المحادثة، جلب النماذج، معرّفات Gemini، خيارات Worker، الخطأ دون فقدان الإعدادات، وتحميل/حفظ شاشة الإعدادات دون فقدان الحقول أو تحديثات النموذج.

## إعادة التشغيل

```sh
cd backend
npm ci
npm test
npm run check
cd ../web
npm ci
npm test
npx expo export --platform android
```

mongodb-memory-server ينزل binary MongoDB محليًا لأول مرة. لا يحتاج الاختبار إلى قاعدة بيانات إنتاجية ولا إلى حسابات AI.

الاختبارات الحية اختيارية وتستهلك جلسة الحساب:

```sh
# From backend/. Do not add credentials to git.
LIVE_PROVIDER=gemini GOOGLE_COOKIES_FILE=/absolute/private/google-cookies.sh npm run test:live
LIVE_PROVIDER=chatgpt CHATGPT_ACCESS_TOKEN='...' npm run test:live
LIVE_PROVIDER=deepseek_worker DEEPSEEK_ACCESS_TOKEN='...' npm run test:live
```

الكوكيز تقرأ كنص أو كقيمة `export BROWSER_COOKIE_HEADER='...'` دون تنفيذ ملف shell. يمكن تغيير `GEMINI_ACCOUNT_INDEX`. تحفظ النتائج الافتراضية في `.local-live/` المستثناة من git. النصوص والكوكيز لا تطبع في السجل. اختبارات CI لا تستعمل الحسابات الحقيقية.

لم يُبنَ APK/IPA ولم يشغّل التطبيق على جهاز فعلي؛ تصدير Expo يتحقق من تجميع JavaScript والأصول، واختبارات الواجهة تستعمل React مع مكونات native محاكاة. نجاح هذه الاختبارات لا يثبت تفعيل خيار التفكير في حساب ChatGPT، ولا يختبر تغييرات البروتوكول المستقبلية في واجهات الحسابات غير الرسمية.

تحديث الاكتشاف التلقائي: اختبارات إضافية تغطي توكن ChatGPT opaque وBearer، معامل sidebar بخمس محادثات، مسار محادثات المشروع، ربط القوائم في طلب واحد، وإنشاء دون prompt يدوي. اختبارات Gemini تغطي GetUserStatus بما فيه status المحذوف/null الطبيعي ورفض 1016، النماذج وترويساتها، القوائم وأحدث response/choice، وحصر اختيارات النماذج في الحساب؛ اختبارات Worker تغطي قوائم النماذج والجلسات. بيانات الحسابات في الاختبارات مصطنعة ولا تستعمل CI الكوكيز الخاصة.

نتيجة حية بتاريخ 2026-10-19: [تقرير اكتشاف Gemini](gemini-discovery-live-result.json). باستخدام الكوكيز الخاصة دون حفظها في git، اكتشف الحساب تلقائيًا، وجلب نموذج الحساب و50 محادثة، وأنشأ محادثة اختبار باستخدام ترويسة النموذج المكتشفة ووصل رد فعلي. تحقق منفصل للقراءة فقط نجح في جلب response/choice لأحدث turn في محادثة موجودة. التقرير لا يتضمن أسماء المحادثات أو المعرّفات أو نصوصها. هذا الاختبار خاص بالاكتشاف والإنشاء، وليس إعادة لاختبار ترجمة فصل كامل؛ نتيجة الفصل الحية السابقة باقية في التقرير السابق.

يمكن إعادة فحص قوائم الحساب فقط دون إنشاء رسائل:

```sh
LIVE_PROVIDER=gemini GOOGLE_COOKIES_FILE=/absolute/private/cookies.sh node --max-http-header-size=262144 scripts/live-account-discovery.js
LIVE_PROVIDER=chatgpt CHATGPT_ACCESS_TOKEN='...' node scripts/live-account-discovery.js
LIVE_PROVIDER=deepseek_worker DEEPSEEK_ACCESS_TOKEN='...' node scripts/live-account-discovery.js
```

اختبارات وضع الفقرات: ChatGPT وDeepSeek يرسلان الفصل كاملًا دون علامات حتى مع خيار محفوظ true. Gemini بدون قيمة محفوظة أو مع true يستخدم الأجزاء وفحص التغطية، ومع false يرسل prompt الأصلي كما هو في طلب واحد. يشمل الاختبار حفظ false/true/false عبر API وMongoDB، وتبديل المفتاح في الموقع وحفظه وإعادة فتح الصفحة على الكمبيوتر والهاتف.
