# إعداد المزودين

## ChatGPT Android

هذا عميل حساب ChatGPT وفق الملف المرفق `chatgpt_android_interactive.py`، عبر `android.chat.openai.com`، وليس عميل مفتاح OpenAI API.

1. في الموقع أضف قالب ChatGPT Android والصق توكن الجلسة، ثم اضغط «ربط الحساب وجلب الخيارات».
2. الخادم يستخرج account ID من JWT، أو يكتشفه من `/backend-api/accounts/check/v4-2023-04-27` للتوكن opaque. لا تطلب الواجهة معرّف الحساب.
3. تُجلب النماذج والمشاريع والمحادثات. اختيار المشروع يطلب `/backend-api/gizmos/{id}/conversations` ويتيح cursor عند توفره؛ sidebar يستخدم خمس محادثات فقط كما في الملف المرفق، ولا يعامل كقائمة كاملة.
4. لكل مهمة اختر نموذجًا ومحادثة، أو اتركها لإنشاء محادثة مستقلة تلقائيًا. زر الإنشاء يهيئ محادثة بتعليمات تلقائية دون رسالة يكتبها المستخدم.
5. احفظ الإعدادات. لوحة تجربة الرسائل والمرفقات اختيارية.

الخيارات الثلاثة:

| الوضع | السلوك |
|---|---|
| لكل مهمة تشغيل `per_job` | محادثة لكل حساب ومزوّد ونوع مهمة ومعرّف job؛ تحفظ في MongoDB وتستأنف عند إعادة التشغيل |
| جديدة `new` | محادثة جديدة لكل عملية توليد؛ أجزاء الفصل الواحد تبقى في نفس المحادثة |
| مختارة `reuse` | متابعة المحادثة المحددة عبر المهام وإعادة التشغيل؛ معرّف المحادثة إلزامي |

اختيار مشروع مختلف يمسح اختيار المحادثة السابقة في الواجهة. عند استخدام محادثة موجودة يجلب العميل `current_node` قبل الإرسال لتجنب استخدام parent قديم. لا يعيد إرسال POST تلقائيًا بعد خطأ اتصال أو HTTP 500، لأن الخادم قد يكون أنشأ الرسالة بالفعل.

رفع الصور PNG/JPEG/WEBP/GIF والملفات يستخدم الرفع الحقيقي وإقرار `/uploaded` من الملف المرفق. تُرسل بيانات المرفقات في الرسالة التالية، ويمكن مسح القائمة المجهزة. الحد الحالي للخادم 10 MB لكل ملف. المرفقات في لوحة التجربة لا تضاف تلقائيًا إلى jobs الترجمة.

**التفكير:** يعرض الموقع مستويات تفكير في قائمة فقط إذا أعلنها endpoint النماذج في الحساب. الاختيار غير `auto` يمرر إلى `thinking_effort`. لا توجد كتابة يدوية للمستويات. لم يتوفر توكن ChatGPT لاختبار تطبيق هذه الخيارات أو الطلب المعدل حيًا؛ اختبارات HTTP تتحقق من صيغة الطلب والاستجابة والمحافظة على الحالة.

## Gemini Web

بروتوكول `gemini_complete.py`: كوكيز حساب Google، ثم `SNlM0e` و`FdrFJe`، ثم StreamGenerate، مع معرّفات المحادثة والاستجابة والاختيار.

- ضع ترويسة الكوكيز كاملة بصيغة `name=value; name=value`. كل حساب في سطر منفصل.
- `geminiDiscovery.service.js` يضيف اكتشاف الحساب والنماذج والمحادثات إلى عميل التوليد المرفق. يستعمل RPCs GetUserStatus (`otAQ7b`) وListConversations (`MaZiqc`) وقراءة أحدث turn (`hNvQHb`). معلومات البروتوكول راجعت بالاستعانة بمصدر https://github.com/HanaokaYuzu/Gemini-API؛ التنفيذ المحلي لا يستبدل عميل التوليد بمكتبة أخرى.
- يكتشف رقم الحساب وbuild label من الجلسة. status غائب/null في GetUserStatus يعني الحالة الطبيعية؛ كود عدم المصادقة 1016 لا يقبل كحساب متصل.
- اختيار المحادثة يجلب conversation/response/choice IDs تلقائيًا. تولد ترويسة النموذج من بيانات نماذج الحساب وتحتفظ في ذاكرة الخادم المؤقتة، ويمكن إعادة جلبها بعد إعادة التشغيل.
- لا تتطلب واجهة الموقع رقم حساب أو JSPB أو build label أو IDs. حقول التخزين القديمة باقية للتوافق. المسارات الجديدة لا تستخدم وضع الضيف تلقائيًا.
- قائمة المحادثات نافذة حديثة محدودة، توسع حتى 200؛ لا تدعي إرجاع كامل التاريخ. مشاريع ChatGPT غير متاحة في هذا البروتوكول ولا تعرض كإمكانية Gemini.
- تظل محادثات المهام مستقلة، وحالة استمرار الترجمة محفوظة في MongoDB. الصور والملفات تستخدم رفع Google الحقيقي من المرفق.

إصلاح اكتمال الفصول: يحفظ قارئ التدفق الأسطر وحروف UTF-8 عبر دفعات الشبكة، ويتعامل مع جميع الإطارات والتعديلات على النص. في المترجم والمترجم الخالص يقسم الفصل إلى أجزاء افتراضية بحجم 2400 حرف، ويطلب لكل فقرة علامة فريدة، ثم يتحقق من العدد والترتيب وعدم الفراغ ومؤشر تقصير واضح وعلامة نهاية. يحتفظ بفواصل المشاهد. يعيد الجزء الفاشل مرتين ثم يفشل الطلب بدل حفظ فصل ناقص. تزال العلامات قبل الحفظ. هذه فحوص تغطية بنيوية؛ لا تضمن وحدها أمانة كل جملة أو خلو النص من أخطاء لغوية.

## DeepSeek 3MH / Telegram

أضف قالب **DeepSeek 3MH / Telegram**. الرابط الافتراضي `https://deepseek-pow.contact-3mh.workers.dev`. ضع **توكن حساب DeepSeek الخاص بك**؛ الموقع لا يوفر حسابًا مجهولًا. الطلب يذهب إلى `/api/chat`، والوكيل يحل PoW تلقائيًا. يدعم التفكير والبحث والنموذج وtemperature وmax_tokens وpresence/frequency penalties، ومحادثات حسب المهمة. في الموقع تُجلب النماذج والجلسات تلقائيًا عبر `/v1/models` و`/api/chat/sessions/list`؛ يختار المستخدم اسم المحادثة، ويحصل الخادم على parent من رد الخدمة إن توفر، دون حقول معرّفات يدوية.

الرابط نفسه أضيف أيضًا إلى قائمة POW في قالب DeepSeek Android القديم عبر `/get_pow`. عند اختيار 3MH كوكيل كامل أو كخادم POW تتلقى تلك الخدمة الخارجية توكن DeepSeek اللازم للعمل.

لم يتوفر توكن DeepSeek للاختبار الحي. جرى التحقق من توثيق الموقع واختبار بناء الطلبات والاستجابات والجلسات والأخطاء محليًا.

## التخزين والصلاحيات

كل مسارات إدارة الحسابات الجديدة محمية بـ `verifyToken` و`verifyAdmin` الموجودين. بحسب السلوك الأصلي فإن `verifyAdmin` يسمح للأدمن والمساهم. بيانات المزوّدين تبقى في Settings وفق تصميم الخادم؛ يجب تقييد الوصول إلى قاعدة البيانات وإعدادات الإدارة.

`ProviderConversation` يحفظ حالة المحادثة تحت مفتاح مجزأ لا يحتوي التوكن نفسه، مع انتهاء بعد 30 يومًا من عدم الاستخدام. قفل الذاكرة يسلسل الطلبات على المحادثة داخل عملية Node واحدة؛ تشغيل عدة replicas على نفس المحادثات المختارة يحتاج قفلًا موزعًا قبل تفعيل هذا الاستخدام.

أزيلت قيم حساب/تخزين ثابتة موروثة من النسخة الجديدة. تُضبط Cloudinary ورموز Android الاختيارية عبر البيئة. لا تسجل الاختبارات الحية الكوكيز أو رموز CSRF أو access tokens.

## مسارات ربط الحساب

`POST /api/translator/accounts/connect` يعيد الاسم المعروض، النماذج، المشاريع والمحادثات المتاحة، capabilities وتحذيرات فشل القوائم المستقلة. `/project-chats` يجلب صفحة محادثات مشروع ChatGPT، و`/conversation` يجلب معلومات الاستمرار تلقائيًا للمزوّد. `/send` يقبل `createNew: true` دون prompt مكتوب ويستعمل تعليمات تهيئة للمهمة. لا تعاد بيانات الكوكيز أو CSRF أو ترويسات النموذج.
